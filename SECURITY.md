# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.x     | ✅ |

## Reporting a Vulnerability

Please do not open public issues for security problems.

Use one of these private channels:

1. GitHub Security Advisory (preferred):
   - https://github.com/lushly-dev/botcore/security/advisories/new
2. If unavailable, open a maintainer contact request in Discussions:
   - https://github.com/lushly-dev/botcore/discussions

Please include:

- Description of the issue
- Reproduction steps
- Impact assessment
- Suggested remediation (if known)

We will acknowledge reports and coordinate responsible disclosure.
